Notes

  • Only in-stock, English, Near Mint listings are compared. If a store does not state a condition, NM is assumed.
  • A listing counts as new when the store's feed says its product was created or published, or its variant was created, within the window. In per-store mode the window is measured back from each store's own newest listing, so a store that has not added stock lately still contributes its latest batch, and the age shown next to each listing tells you how old that batch is. Stores can reset these dates when they re-import stock, so watch the Latest batch column in the Store check table.
  • Each new listing is compared with the cheapest in-stock price at every other store, new or old. A new listing that no other store carries cannot be judged, so it does not appear.
  • A new listing with no set is compared by card name, foil type, finish and treatment instead of being skipped. It is judged against every set the card exists in, so some flags will be the wrong printing. Treat the set-unknown table as a list to check by hand.
  • Stores marked as whole-store feeds are read from their full product list and filtered to Magic cards using the Scryfall set list, so a missing set list means those stores return nothing.
  • Prices are the cheapest in-stock listing per store, in AUD, and do not include shipping. For cards under about $15, shipping can cancel out the saving.
  • Two listings count as the same card only when name, set, foil type, treatment and collector number agree, except for the set-unknown comparison described above.
  • Set names loaded from Scryfall: 1066.
